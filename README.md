# 🔬 Нормативы ЭСПЦ

Двухфайловое веб-приложение для нормирования трудозатрат ремонтных работ электросталеплавильного цеха (ЭСПЦ). Работает без backend, полностью в браузере (включая мобильные устройства). Данные сохраняются в `localStorage` под префиксом `esp_`.

## 📂 Состав проекта

- `index.html` — стартовая страница (портал выбора версий).
- `esp-full.html` — расширенная версия (v4.10) для нормировщиков и администраторов.
- `esp-lite.html` — ограниченная версия (v4.10) для инженеров и мастеров участков.

## 🚀 Быстрый запуск

### Вариант 1: Локальный запуск (Windows / macOS)
1. Скачайте все три файла (`index.html`, `esp-full.html`, `esp-lite.html`) в одну папку.
2. Откройте `index.html` двойным кликом (запустится в браузере по умолчанию).
3. Или используйте локальный сервер (рекомендуется для корректной работы всех функций):
