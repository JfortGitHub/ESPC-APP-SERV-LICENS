# 🔬 Нормативы ЭСПЦ (ESP Norms)

Веб-приложение для нормирования трудозатрат ремонтных работ электросталеплавильного цеха (ЭСПЦ). Работает без backend, полностью в браузере (включая мобильные устройства). Данные сохраняются в `localStorage` под префиксом `esp_`.

## 📂 Состав проекта

- `index.html` — стартовая страница (лендинг) с выбором версии.
- `esp-full.html` — расширенная версия (Full V4.17) с плагинами, аналитикой и расширенным экспортом.
- `esp-lite.html` — ограниченная версия (Lite V4.17) с облегченным интерфейсом.
- `manifest.json` — Манифест PWA для установки на устройства.
- `sw.js` — Service Worker (стратегия Network First).
- `icon-192.png` / `icon-512.png` — Иконки приложения.
- `README.md` — Документация.

## 🚀 Ключевые возможности

### Базовый функционал (Full & Lite)
- **База нормативов**: Поиск, фильтрация по участкам, категориям и типам ремонта.
- **Калькулятор трудозатрат**: Суммирование чел-часов, расчет дней и размера бригады.
- **Технологические карты**: Создание, просмотр, печать и экспорт (PDF, DOCX, TXT, CSV).
- **Справочник оборудования**: Учет оборудования с привязкой к ТМ-кодам.
- **Мгновенное автосохранение**: Любое действие в калькуляторе (добавление, удаление, изменение количества) сразу пишется в `localStorage` и синхронизируется между версиями.
- **Светлая/Тёмная тема**: Поддержка переключения интерфейса (кнопка в шапке).

### Расширенные функции (Только Full)
- **Умный Drag & Drop (ТМ)**: Перетаскивание файлов (выгрузка из 1С/Excel) в поле ТМ. Скрипт автоматически извлекает коды, сопоставляет с введенным оборудованием и подставляет нужный (или предлагает выбрать из списка).
- **Согласование (Workflow)**: Полноценный маршрут (Черновик → На проверке → Утверждён → Архив) с ролями и историей.
- **Версионирование**: Сохранение истории изменений нормативов, сравнение версий (Diff) и откат.
- **HARD-дедупликация**: Блокировка добавления записей с дублирующимися кодами.
- **Импорт PRO**: Загрузка нормативов и оборудования из XLSX, CSV, JSON с предпросмотром.
- **ML-прогноз**: Эвристический расчет норматива на основе похожих операций.
- **Аналитика**: Сводные отчеты по участкам и категориям.

### Управление данными (Только Full, роль Администратор)
- **Редактирование записей**: Возможность открыть сохраненный норматив или оборудование, изменить любые поля и сохранить (кнопка «✏️»).
- **Управление пользователями**: Добавление/удаление пользователей, сброс паролей.

## 👥 Роли пользователей
1. **Admin (Администратор)**: Полный доступ. Может редактировать любые нормативы, управлять пользователями, просматривать историю версий и workflow.
2. **Engineer (Инженер)**: Может создавать нормативы, добавлять оборудование, работать с калькулятором и экспортом. Не может удалять чужие записи или менять пользователей.
3. **User (Пользователь)**: Базовый доступ (просмотр, поиск, калькулятор).

*Демо-доступы (кнопки на экране входа):*
- `admin` / `admin123`
- `engineer` / `eng123`
- `user` / `user123`

## 💾 Хранение данных
Все данные хранятся локально в браузере под ключами:
`esp_users`, `esp_session`, `esp_custom`, `esp_equip`, `esp_cards`, `esp_workflow_states`, `esp_workflow_history`, `esp_autosave_calc`, `esp_autosave_tab`, `esp_theme`.

*Внимание (iPad/Safari)*: Данные могут очищаться, если приложением не пользовались 7 дней. Для надежности используйте установленное PWA-приложение.

## 🛠️ Технические детали и разработка

- **Стек**: Чистый HTML/CSS/JS (ES6+). Без сборщиков (Webpack, Vite) и сторонних фреймворков.
- **Стиль кода**: Без точек с запятой (ASI), одинарные кавычки в JS, двойные в HTML. Функции `tabXxx()` рендерят раздел, `renderXxx()` возвращают HTML-строку.
